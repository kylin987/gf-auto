# 闲鱼新会话欢迎过滤设计

## 目标

只有真正新建的闲鱼商品会话可以上报 `session_opened`；买卖双方之前聊过的历史会话再次打开或输入时不得发送欢迎语。

## 方案

- 使用闲鱼会话的 `createTime/createAt` 判断是否为新会话，统一阈值为 120 秒。
- 正式 `sessionArouse` 与 `objectType=40006` 推断路径使用同一判断。
- 创建时间缺失、无效、超过 120 秒或明显晚于当前时间时，不上报欢迎事件。
- 保留现有 `storeId + buyerId + itemId` 持久化去重。

## 验证

- 新建 1 秒的会话继续上报。
- 已创建 5 分钟的正式唤醒会话不再上报。
- 已创建 5 分钟的 `40006` 候选会话不再上报。
- 其他卖家的会话仍然拒绝。
